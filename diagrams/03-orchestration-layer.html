编排层架构 — LangGraph TickGraph
"指挥官"：只发号施令不亲自下场 · StateGraph 主图 + 9 子图 · State 完全独立无继承
OverallState 主图 — 7 Phase 线性流转
P1
DM 创造情境
输入: WorldState + DM记忆 + StoryArc/伏笔 + 上轮plot_brief
输出: DMInstruction[] + plot_brief + SceneDirection
DM 搭舞台、设挑战、指定参演人员，不替角色决策
P2
WorldEngine 执行
执行 DMInstruction[]: 场景实例化 + Actor 动机注入 + 环境变化
输出: 世界变化 Event[]
P3
角色并行决策
Send fan-out: LangGraph Send 并行唤醒 PC + Actor
读同一份 WorldState 快照（角色间互不干扰）
只唤醒 DM 指定的 featured_pcs + featured_actors
单个角色失败降级为 wait，不阻断其他
P4
Engine 条件路由
根据 action_type 路由: attack→CombatEngine | talk→DialogueEngine | move/interact→ExplorationEngine
每 Tick 检查 QuestEngine 任务完成
战斗触发→CombatGraph 独立 tick 子循环（外层暂停）
P5
状态更新
合并 WorldEngine + 各 Engine 结果 → WorldState
检查主角团变动（死亡/离开/加入）
输出: state_diff + cast_changes
P6
DM 叙事渲染
输入: plot_brief + 实际执行结果（含战斗结果）
DM 基于实际结果讲故事
记录 BranchPoint + 伏笔回收
P7
反思 + 摘要
PC 深度反思（importance≥100）| Actor 轻量反思（≥200）
StorySummarizer 每 10 步压缩原始 Event → 剧情梗概
